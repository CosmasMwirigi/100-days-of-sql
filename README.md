# 100 Days of SQL

I'm learning SQL in public on my way to becoming a data analyst. Every day I study, take handwritten notes, and turn them into documentation and code in this repo.

## Why I'm doing this

The job market is tough. Learning in public keeps me consistent and shows exactly what I know, one day at a time.
